# ``OnboardingStudio``

Build polished onboarding experiences with SwiftUI.

## Overview

`OnboardingStudio` is a reusable onboarding library for iOS apps that want more than static screenshots or generic first-run screens. The package combines:

- a high-level onboarding flow container,
- reusable visual components,
- a theme system,
- modern motion defaults,
- and a separate spotlight tutorial module shipped as `SpotlightGuide`.
