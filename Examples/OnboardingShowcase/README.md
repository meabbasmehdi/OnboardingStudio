# OnboardingShowcase

This folder contains a source-ready SwiftUI showcase app for `OnboardingStudio` and `SpotlightGuide`.

## What It Demonstrates

- premium onboarding flow presentation
- theme switching between `studio` and `sunrise`
- custom page rendering with the high-level flow container
- gesture navigation and indicator updates
- contextual spotlight guidance

## Contents

- `OnboardingShowcaseApp.swift`
- `ShowcaseRootView.swift`
- `ShowcaseSpotlightDemoView.swift`

The example is intentionally lightweight and source-focused so it can live next to the package cleanly. Open the folder in Xcode and wire it into your preferred app project layout if you want a bundled iOS sample target.
